# 帳號、審核與商機權限 — 決策紀錄

> 用途：實作前共識；開新對話時請 `@docs/account-permission-decisions.md`。  
> 更新日期：2026-09-14

---

## 兩條線，不要混

### A. 帳號申請（註冊／後台審核／開帳）

管：誰能登入、身分權限、能看哪些商機。

### B. 商機報備

管：已登入者登錄案子。

- **報備者資料**：登入後自動帶入「公司名／該業務姓名」（經銷、原廠同一格式），唯讀  
- **客戶資料**：無論誰報備都必填  
- 表單**沒有**「通路公司」欄位；勿用此詞描述商機表單  
- 經銷綁定的「一位原廠業務」與商機上的「原廠所屬業務」**可以是不同人**

會員編號 ≠ 商機編號。帳號審核 ≠ 商機審核。

## 帳號／註冊（已確認）

| 項目 | 決策 |
|------|------|
| 公開註冊 | **一張表**；申請人**不選身分權限** |
| 總管理者 | **只由內部開帳**，不走公開註冊 |
| 原廠主管／原廠業務／經銷 | 可走公開註冊；後台再指定身分權限 |
| 總管理者開帳 | 可於後台**自行幫他人開帳**，並直接指定身分權限／等級／綁定 |
| 會員編號 | 註冊或開帳時產生，**不可改** |
| 直屬主管 | 註冊不填；**審核後**由總管理者指定 |
| 台灣／海外 | 審核時**內部自選**，不依國家自動帶入 |
| 核准後可否再改 | **皆可改**：身分權限、地區、等級、綁定業務／主管 |
| 同統編第二個經銷帳號 | **允許**，當獨立帳號；**不做合併**（合併算另一功能） |
| 統編已存在 | 審核時**只提醒、不自動擋**（原廠多人同統編） |
| 會員等級 | 一般／黃金／白金／鑽石；**只做標示**，不管下載／課程／價格 |

### 審核頁勾選邏輯

- **台灣／海外經銷**：等級＋綁定**一位**原廠業務  
- **原廠業務**：指定**一位**直屬主管（一位主管可掛多名業務，無再下一層）  
- **原廠主管**：不設等級、不掛主管  
- 勾成經銷＝此帳號代表該公司（看商機規則見下）；勾成原廠＝內部帳號，不當新經銷公司

### 列表 UI（不撐爆）

- 編號嵌在公司名稱下方（列表不顯示統編）
- 身分權限獨立一欄，純文字；已核准經銷顯示為「國內經銷商/黃金」這類格式（無等級框）
- 原廠業務欄：已核准經銷顯示正式綁定姓名；審核中／未綁定若有自填則顯示「申請：某某」，否則「—」
- 註冊「原廠業務姓名」為申請參考，placeholder：填寫目前所屬業務窗口姓名；正式綁定於後台核准時指定
- 國家／地區不顯示於列表（詳情／預覽可見）
- 列表依申請日新到舊排序（最新在第 1 頁）；同分再依會員編號新到舊
- 點列開啟預覽燈箱；編輯圖示／「前往審核」才進編輯頁
- 篩選：申請狀態 ＋ 身分權限（原廠業務／海外經銷商／國內經銷商；原廠含主管＋業務）
- 勾身分權限／等級只在審核（或開帳）頁，不在列表加可勾欄

## 商機可見範圍（已確認）

同一套規則套用於：**清單／明細／搜尋／統計／匯出**。人員異動後依「當下」關係重算。

| 身分權限 | 可見範圍 |
|------|----------|
| 台灣／海外經銷（四等級相同） | **只看自己新增的商機** |
| 原廠業務 | 自己負責的 ＋ 目前綁在自己名下之經銷所報的 |
| 原廠業務主管 | 自己新增的 ＋ 綁在自己名下的 ＋ **直屬**業務看得到的 ＋ 自己被填成「原廠所屬業務」的（即使非自己新增） |
| 總管理者 | 全部 |

### 人事異動

- 改經銷的「綁定原廠業務」**不會**自動改舊商機  
- 舊案需總管理者於後台改該筆商機的「原廠所屬業務」後，可見範圍才換人

### 這版不做

- 同公司帳號合併／共用商機  
- 等級管下載、課程、價格  
- 公開註冊選身分權限
