## 兩條線，不要混

### A. 帳號申請（註冊／後台審核／開帳）

管：誰能登入、身分權限、能看哪些商機。

### B. 商機報備

管：已登入者登錄案子。

- **報備者資料**：登入後自動帶入「公司名／該業務姓名」（經銷、原廠同一格式），唯讀  
- **客戶資料**：無論誰報備都必填  
- 表單**沒有**「通路公司」欄位；勿用此詞描述商機表單  
- **經銷不綁業務**（2026-10-02 異動）：經銷只有一個「主要業務窗口」文字欄，僅供參考、不影響商機  
- 商機的**承接業務**（`oem_sales_id`）才決定歸屬：
  - 新增／補件表單一律用手填「原廠業務」姓名（僅供參考）
  - 經銷送出後 `oem_sales_id` 為空（待指派）；原廠內部人員新增時仍可預設自己
  - **僅總管理者審核**時用下拉指派正式承接業務；通過時必填；退回／失效可不填；之後可再改

會員編號 ≠ 商機編號。帳號審核 ≠ 商機審核。

### 示意身分切換（靜態預覽）

權限資料為七種（總管理者／系統管理員／原廠高階主管／原廠主管／原廠業務／國內經銷／海外經銷），側邊欄預設只給客人看兩種：

- **總管** → `admin`
- **非總管** → `dealer_tw`（一般使用者示意）；右上角顯示「一般使用者」

工程師要測可見範圍時再開完整身分：

- 網址加 `?roles=full`（會寫入 localStorage，之後重整仍是詳細身分）
- 或雙擊側邊欄「演示用」；切回客人示意用 `?roles=simple` 或再雙擊一次（徽章會變成「工程師預覽」）
- 完整模式含 **系統**（系統管理員），左側選單依該帳號勾選的權限顯示

## 帳號／註冊（已確認）

| 項目 | 決策 |
|------|------|
| 登入口 | **同一頁** `/login`（Email＋密碼）。系統管理員／總管／原廠／經銷不分開登入 |
| 公開註冊 | **一張表**；申請人**不選身分權限**；系統管理員**不走**公開註冊 |
| 總管理者 | **只由內部開帳**，不走公開註冊 |
| 系統管理員 | **只由總管理者於系統管理開帳**，勾選左側選單後走同一登入口 |
| 原廠高階主管／原廠業務主管／原廠業務／經銷 | 可走公開註冊；後台再指定身分權限 |
| 總管理者開帳 | 可於後台**自行幫他人開帳**，並直接指定身分權限／等級／綁定 |
| 夥伴初始密碼 | **內部開帳必填**；總管設定後告知對方（對方用公司 E-mail 登入） |
| 重設夥伴密碼 | **僅總管理者**可在夥伴編輯頁重設（新密碼＋確認新密碼，不需目前密碼）；夥伴本人改密走「用戶資料」 |
| 會員編號 | 註冊或開帳時產生，**不可改** |
| 直屬主管 | 註冊不填；**審核後**由總管理者指定 |
| 台灣／海外 | 審核時**內部自選**，不依國家自動帶入 |
| 核准後可否再改 | **皆可改**：身分權限、地區、等級、綁定業務／主管 |
| 同統編第二個經銷帳號 | **允許**，當獨立帳號；**不做合併**（合併算另一功能） |
| 統編已存在 | 審核時**只提醒、不自動擋**（原廠多人同統編） |
| 會員等級 | 一般／黃金／白金／鑽石；**只做標示**，不管下載／課程／價格 |

### 審核頁勾選邏輯

- **台灣／海外經銷**：等級（必填）＋主要業務窗口（選填文字，不影響商機）  
- **原廠業務**：指定**一位**直屬業務主管（一位主管可掛多名業務）  
- **原廠業務主管**：指定**一位**直屬高階主管（一位高階主管可掛多名業務主管）；不設等級  
- **原廠高階主管**：不設等級、不掛主管  
- 勾成經銷＝此帳號代表該公司（看商機規則見下）；勾成原廠＝內部帳號，不當新經銷公司

### 列表 UI（不撐爆）

- 會員編號獨立一欄，放在最前面（列表不顯示統編、聯絡方式；E-mail 與電話在預覽／編輯查看）
- 身分權限獨立一欄，純文字；已核准經銷顯示為「國內經銷商/黃金」這類格式（無等級框）
- 主要業務窗口不顯示於列表與預覽；只在「審核與身分權限」勾成經銷時出現，僅供參考
- 「所屬業務」在申請人後面。只有審核時從下拉選到某一位原廠業務（`assigned_sales_id`）才顯示姓名，未選為「—」；不沿用註冊的主要業務窗口文字
- 註冊「主要業務窗口」選填，僅供參考
- 國家／地區不顯示於列表（詳情／預覽可見）
- 列表依申請日新到舊排序（最新在第 1 頁）；同分再依會員編號新到舊
- 點列開啟預覽燈箱；編輯圖示／「前往審核」才進編輯頁
- 篩選：申請狀態 ＋ 身分權限（原廠業務／海外經銷商／國內經銷商；原廠含高階主管＋業務主管＋業務）
- 勾身分權限／等級只在審核（或開帳）頁，不在列表加可勾欄

## 商機可見範圍（已確認）

同一套規則套用於：**清單／明細／搜尋／統計／匯出**。人員異動後依「當下」關係重算。

| 身分權限 | 可見範圍 |
|------|----------|
| 台灣／海外經銷（四等級相同） | **只看自己新增的商機** |
| 原廠業務 | 自己新增的 ＋ 承接業務是自己的 |
| 原廠業務主管 | 自己新增的 ＋ 承接業務是自己的 ＋ **直屬**業務看得到的 |
| 原廠高階主管 | 自己新增的 ＋ 承接業務是自己的 ＋ **直屬**業務主管看得到的（含其下業務） |
| 總管理者 | 全部（**不含他人暫存**） |

「待指派」（尚無承接業務）的商機：只有建立的經銷與總管理者看得到。

### 暫存

- 暫存只存在**新增者自己的帳號**（清單／明細／搜尋／統計／匯出同一套）
- **送出進入「審核中」後**，總管理者才看得到；其餘身分仍依上表

### 列表動作

- **結案**：僅總管理者看得到；已到期才可按

### 人事異動

- 經銷與業務無綁定，人事異動不影響經銷  
- 總管理者改某筆商機的承接業務後，可見範圍**立即**換人（舊業務看不到，除非是他新增的或他是新業務的主管）

### 這版不做

- 同公司帳號合併／共用商機  
- 等級管下載、課程、價格  
- 公開註冊選身分權限

## 現況原型備註

- 預覽身分權限：總管／系統管理員／主管／業務／國內／海外（各綁示範 `partnerId`）；`oem_director` 已入資料與權限規則，側邊預覽按鈕暫不加  
- 系統管理員由總管理者於「系統管理」開帳，並勾選左側選單權限；「系統管理」本身不開放勾選  
- 商機可見範圍已依身分權限過濾；以商機的承接業務（`oem_sales_id`）為準，經銷不綁業務；高階主管可看直屬業務主管團隊  
- 組織關係：高階主管 → 業務主管 → 業務（`manager_id`）  
- 承接業務選項由 `bootstrap.php` 的 `oem_staff_options()` 從已核准原廠人員產生  
- 商機表單已有「報備者資料」「客戶資料」區塊（報備者自動帶入見第 6 段）
