# 商機續期審核說明（給業主）

業主：UPAS Partners Portal  
日期：2026-11-05  
案名：合作夥伴入口｜商機續期  

---

## 0. 一句話說明

商機本身的狀態，與「這次有沒有在申請續期」是分開記錄的；列表上看到的「續期審核中」，是依**最新一筆續期申請**顯示給使用者看的狀態。

---

## 1. 兩種狀態（概念）

### | 商機狀態
・記錄這筆商機本身進度，例如：審核中、已核准、即將到期、退回補件、已結案…  
・續期申請**不會永久改掉**商機本質狀態；審核通過後，列表會回到一般狀態（多為「已核准」）。

### | 續期狀態
・另有「續期申請」紀錄（後端獨立一筆／一表）。  
・每次送出續期＝新的一筆申請，總管理者逐筆審核「要不要延長保護期」。  
・畫面目前只顯示**最新一期**續期內容；歷史紀錄畫面本期不做。

---

## 2. 畫面上怎麼呈現（與版面對齊）

### | 商機列表
・一般情況：狀態欄顯示商機狀態（如「已核准」「即將到期」）。  
・若最新一筆續期尚在待審：狀態欄改顯示「續期審核中」，方便總管理者一眼辨識。  
・續期審核通過後：狀態欄回到一般商機狀態（如「已核准」），並依結果更新保護到期日。  
・列表篩選提供「續期審核中」，方便只看待審續期案件。

### | 續期申請頁（經銷／報備端）
・可對符合條件的商機提出續期（延長保護天數）。  
・欄位含：續期天數、續期原因、佐證檔案等。  
・送出後進入待審；列表狀態顯示「續期審核中」。  
・送出後**無獨立成功頁**，以提示訊息確認已送出。

### | 商機審核頁（總管理者）
・若為最新一期待審續期：頁面標示為「續期審核」，並顯示「續期申請內容」區塊。  
・總管理者可審核通過／退回（續期場景不需再指派承接業務）。  
・通過：保護到期日依續期內容延長；列表回到一般狀態。  
・退回：保護到期日維持原日；可依流程再補件／再申請（畫面以最新一期為準）。

---

## 3. 流程摘要（給業主對照）

1. 商機已核准（或即將到期）→ 使用者送出續期申請  
2. 系統新增一筆「續期申請」待審 → 列表顯示「續期審核中」  
3. 總管理者於審核頁確認最新一期續期資料 → 通過或退回  
4. 通過 → 延長保護期，列表回到「已核准」等一般狀態  
5. 之後若再次續期 → 再產生新的一期申請；畫面仍只看最新一期  

---

## 4. 本期範圍與後續

### | 本期有做
・列表「續期審核中」顯示與篩選  
・續期申請／續期審核版面（最新一期）  
・審核通過後回到一般商機狀態  

### | 本期不做
・歷次續期紀錄列表、逐筆顯示／隱藏開關的管理畫面  
・（後端仍可留存每筆續期紀錄；前台先不開歷史介面）

### | 待後端對接時確認
・列表「續期審核中」由最新待審續期推導顯示（商機狀態與續期狀態分開存）  
・退回時商機狀態是否維持已核准／即將到期，僅續期狀態為退回  
・同一商機是否允許「上一筆未審完又送下一筆」（建議：待審中不可重送）

## 5. 給技術對照（精簡）

| 項目 | 說明 |
|------|------|
| 資料 | 商機一筆；續期申請可多筆（一商機對多續期） |
| 前台顯示 | 只取最新一筆續期 |
| 列表狀態 | 有待審續期 → 顯示「續期審核中」；否則顯示商機狀態 |
| 審核通過 | 更新保護到期日；列表回復一般商機狀態 |
